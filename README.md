# Team 7 Escape Serge

## Building the code

Run the `build.py` script and look for the executable in the `out` directory

## Project structure

- Headers `.h`/`.hpp` in `include`
- Source files `.ccp`, UI files `.ui` and Ressources files `qrc` in `src`
- Assets (images, etc.) in the `assets` directory
